## 要做什麼

## 為什麼

KPL 儀表板新增「帳號管理」功能：管理員可在線上新增帳號、設定密碼與權限級別（A/B/C）。新版程式（已部署）會把帳號存進這張新表 `user_accounts`。**表還沒建之前，「帳號權限」頁的帳號管理區塊會顯示「帳號表尚未建立」提示**（不會壞，只是還不能新增帳號）。

> 註：原本用環境變數 `LOCAL_ACCOUNTS` 設定的帳號（例如 AD123）不受影響，仍可登入。這張表只是讓帳號改用線上管理。

## 這份 SQL 會做的事

1. 建新表 `kpl_dashboard.user_accounts`（帳號 / 密碼 hash / 隨機 salt / 級別 A,B,C / 啟用狀態）
2. 加欄位註解

全程包在 `BEGIN ... COMMIT` 交易內，中途失敗會自動 rollback。建表用 `IF NOT EXISTS`，重複執行安全。**無破壞性操作**（不刪除、不修改任何既有表）。

## 驗證（執行完跑這段）

```sql
WHERE table_schema = 'kpl_dashboard' AND table_name = 'user_accounts'
ORDER BY ordinal_position;
```

預期看到 user_id / password_hash / password_salt / level / is_active 等欄位。
